# JARVIS

Personal voice assistant for Windows. Uses only Python (built-in libraries) and Microsoft Edge / Google Chrome.

- Run `start_jarvis.bat` once. A **JARVIS** icon is created on the Desktop.
- Settings (gear icon): AI key, language, voices, updates.
- Updates: open Settings → **Update now**. JARVIS downloads the newest version from this repository and restarts itself.

Your AI key and reminders are stored in `%USERPROFILE%\.jarvis`, never in this repository.
